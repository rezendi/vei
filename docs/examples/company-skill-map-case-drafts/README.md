# Company Skill Map Case Drafts

Company-specific skill-map drafts are intentionally not published in this
public repository. They are derived from private tenant histories and can include
customer names, counterparties, email subjects, internal operating details, and
state-point labels.

For public examples, use synthetic or public-record fixtures under
`docs/examples/`, such as Clearwater or Enron. For private tenant work, keep
draft skill maps in ignored local output directories such as `_vei_out/` or in a
private workspace with explicit review before promotion.
